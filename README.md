# Анализ разности фаз каналов USRP X310 (4 приёмных канала)

Пакет MATLAB-скриптов для поиска закономерности в разности фаз между
каналами при приёме общего тона через разветвитель (fc + fd → тон fd на выходе).

## Физика задачи

Если на все 4 канала через разветвитель подаётся синусоида fc + fd, а приём
идёт на несущей fc, то на выходе каждого канала будет тон fd, но с разной
фазой: канал k стартует с постоянной задержкой τ_k, поэтому

    φ_k = φ_0 − 2π·fd·τ_k  →  Δφ_kj = −2π·fd·(τ_k − τ_j)

**Искомая закономерность:**
1. Δφ между каналами НЕ зависит от fc (900 или 1000 МГц) — зависит только от fd;
2. Δφ линейна по fd: Δφ[град] = −0.36·fd[МГц]·Δτ[нс] (с заворотом на 360°);
3. Наклон этой прямой = межканальная задержка Δτ = const (калибровочная
   константа приёмника). Измерив Δφ на двух и более fd, можно восстановить Δτ
   и потом компенсировать его при пеленгации.

Важно про неоднозначность: измеряется Δφ по модулю 360°, поэтому задержки
τ и τ + 1/gcd(fd) неразличимы. Если все fd кратны 5 МГц — задержка известна
с точностью до 200 нс. Для однозначности нужны взаимно простые fd
(например, 10 и 13 МГц) — скрипт сам предупреждает об этом.

## Как пользоваться

### Скрипт 3 — просмотр одной записи
```matlab
cd matlab
plot_iq_capture            % читает pelengator_iq_capture.bin из ../upload
```
Настройки в начале скрипта: `File` (имя/путь файла), `NPlot` (сколько
отсчётов показывать), `SavePng`. Открывает 4 окна: осциллограммы I/Q всех
каналов, спектры, годографы IQ, огибающие.

### Скрипт 4 — анализ серии data_<time>_<f>_<fd>.bin
```matlab
cd matlab
analyze_phase_diffs        % DataDir = '../testdata' по умолчанию
```
Настройки: `DataDir` — папка с файлами; `SNRMin` — порог SNR тона (дБ);
`SaveCsv`/`SaveMat`/`SavePng` — выгрузка. Для реальных данных укажите:
```matlab
DataDir = 'D:\measurements'   % или другой путь
```

Что выдаёт скрипт 4:
- консольная таблица: Δφ(k−1) каждого файла + SNR + отметка «тон не обнаружен»;
- окно 1: теплокарты матриц Δφ 4×4 (φ_i − φ_j) по каждому файлу;
- окно 2: (а) столбцы Δφ(k−1) по файлам; (б) Δφ от fd — точки ложатся на
  прямую, если задержки постоянны; (в) Δτ, оценённая по каждому файлу отдельно;
- восстановление Δτ по всем файлам (grid-search с заворотом фазы) с СКО невязки;
- `phase_diff_results.csv` и `phase_diff_results.mat` в папке данных.

- Δφ от fc не зависит (файлы 1000_10 и 900_10 дают идентичные Δφ) —

- ошибка восстановления Δφ < 0.05° при SNR 62 дБ.

## Про реальный файл pelengator_iq_capture.bin

В выложенном примере **тона нет** — запись шумоподобная (SNR пика ≈ 5 дБ,
«пик» спектра скачет по частоте от сегмента к сегменту). Обнаружен общий
широкополосный компонент в каналах (когерентность 0.13–0.19; фаза
кросс-спектра пары ch0–ch1 плоская ≈ 90° по всей полосе — это похоже на
наводку/общий шум тракта, а не на полезный сигнал). Поэтому оба скрипта
детектируют отсутствие тона (порог SNRMin = 20 дБ) и помечают такие файлы,
чтобы Δφ по ним не принимались за калибровку. Для реальной калибровки
запишите файлы с поданным через разветвитель тоном fc + fd.

## Совместимость

Скрипты проверены в GNU Octave 9.4 и написаны в подмножестве MATLAB:
без тулбоксов (Signal/DSP не нужны), локальные окна Ханна/FFT-оси
реализованы внутри. В MATLAB R2016b+ работают без изменений.
